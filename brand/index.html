Shipshape
One standard, every project.

The reference is an admiralty chart and a drafting rule, not a SaaS dashboard. Warm paper, sea-green ink, hairline rules, and four signal colours reserved for readiness alone. The surface stays quiet so the status does all the shouting — because the product's only job is to tell you plainly what is not ready.

Settled

  • Single light ground. Quotefront owns the dark end of the Northbound range; Shipshape is read like a document, not watched like a monitor.
  • Sea-green is the only accent. One colour, everywhere an action lives.
  • The four signal colours never do brand duty.
  • Figures are always mono and tabular. This is an instrument.

Still open

  • The wordmark is set type, not a drawn logo. It wants a proper mark before anything goes public.
  • Fraunces is doing display work at one weight — the soft and wonk axes are untested.
  • No iconography yet. Arrows on the board are text characters standing in.
  • Empty and error states exist in code but have not been designed with care.
